#     Checklist de Qualidade dos Dados antes dos Gráficos
**Objetivo:** Verificar se base de dados está limpa, consistente e pronta antes de gerar visualização ou graficos.
* **Prompt Original:** "Quero ferificar se minha base está pronta para análise. Quais itens devo revisar para garantir a qualidade dos dados antes de gerar os gráficos?
*  **Dica de Segurança e privacidade (LGPD):** Ao rodar este prompt em IAs públicas (como ChatGPT ou Claude), certifique-se de **nunca** fazer o upload da sua base de dados real se  ela contiver informações confidenciais de clientes. Em vez disso, cole apenas o nome das colunas e o tipo de dados para que a IA monte o checklist de forma genérica e segura.
